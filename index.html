DNS Troubleshooting Lab

Problem

Client could not join the Active Directory domain.

Investigation

Used ipconfig, ping and nslookup to diagnose the issue.

Root Cause

Incorrect DNS server configuration.

Solution

Configured the client to use the Domain Controller as its Preferred DNS server.

Outcome

Successfully joined the domain.
